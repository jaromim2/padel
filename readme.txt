Logged-in MVP for uploading a short padel video, tracking status, and deleting the private file and analysis record.

== Description ==

This plugin adds a simple "ניתוח חבטה" page, a private upload flow, REST status polling, and a mock processor that moves records from uploaded to processing to completed.

== Installation ==

1. Upload the plugin folder to `wp-content/plugins/padel-video-analysis`.
2. Activate the plugin in WordPress admin.
3. Open the "ניתוח חבטה" page created by the plugin.
